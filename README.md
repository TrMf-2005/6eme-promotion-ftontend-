# Site de la promo — frontend

HTML / JS vanilla, comme les autres projets. Thème beige/orange/jaune validé.

## Avant de déployer
Dans `js/api.js`, remplace `API_BASE` par l'URL réelle du backend une fois
déployé sur Render.

## Structure
- `index.html` — accueil + vérification du mot de passe commun
- `formulaire.html` — inscription / mise à jour (photo, réseaux, autres détails)
- `annuaire.html` — annuaire public avec recherche
- `confidentialite.html` — politique de confidentialité
- `admin/` — espace admin (login, tableau de bord, membres, réglages,
  historique et gestion des admins réservés au principal)

## À faire ensuite
- Remplacer les couleurs si besoin de retouches fines
- Brancher le déploiement Vercel (comme les autres projets)
- Ajouter le tracker de visite anonyme (niveau 1) prévu au squelette commun
